# Room + Porch: Kitchen and Toilet Plan

Interactive 3D model and floor plan for converting the front porch into a kitchen and toilet.

- **3D model:** rotate, zoom, and toggle the roof, ceiling and labels
- **Floor plan:** existing layout and proposed layout, with dimensions
- **Notes:** room schedule, block quantities, structural notes and site photos

Dimensions are estimates from site photos (about ±10%). Confirm them on site before construction.

Open `index.html` in a browser, or view the live page on GitHub Pages.
